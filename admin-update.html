Weekly Update Guide

New Week,
New Content.

Use this page each week to update the homepage with the latest sermon and devotional. Follow the steps below and you'll be done in under 5 minutes.

Step 1: New Sermon
Update the homepage to show the latest episode from Buzzsprout
1
Get the episode ID from Buzzsprout
Go to buzzsprout.com/2608288/episodes, click your newest episode, and copy the number from the URL. It looks like: buzzsprout.com/2608288/episodes/19087134
2
Paste the episode ID below
This will replace the player src in index.html
Paste an episode ID above to see the preview
3
Open index.html on GitHub and make the change
In index.html, find the two places that say 19087134 (the current episode ID) and replace both with your new ID. One is in the div id, one is in the script src.
Open index.html on GitHub →
Step 2: New Devotional
Swap the homepage devotional card to point to your newest post
1
Create the new devotional page
Copy an existing devotional file (e.g. devotional-ephesians-3.html), rename it for the new week, update the title, Scripture, content, and Buzzsprout episode ID inside it. Upload it to GitHub.
2
Fill in the new devotional details
3
Replace the devotional card in index.html
In index.html, find the section that says devotional-ephesians-3.html and replace the filename, series label, title, and scripture with your new ones. Here's exactly what to paste:
New card HTML (copy & paste into index.html)
Fill in the fields above to generate the card HTML
Open index.html on GitHub →
Step 3: Commit and Verify
Save your changes and confirm the site updated
1
Commit your changes on GitHub
After making your edits in the GitHub editor, click Commit changes, write a message like Week 4 update: sermon + devotional, and click the green button. Netlify deploys automatically in about 30 seconds.
2
Verify it's live
Visit gatheringctx.org and confirm the new sermon player and devotional card are showing. If it looks the same, wait 30 more seconds and hard refresh (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac).
3
Also update devotionals.html
Add the new devotional card to devotionals.html so it shows in the full archive. Copy an existing card block, update the filename, title, series, and scripture. Place it at the top of the grid so newest is first.
Open devotionals.html on GitHub →
